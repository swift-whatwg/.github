# Swift WHATWG

Use this organization when you need a Swift implementation of a WHATWG standard. There is one package per specification, named `swift-whatwg-<spec>`, which follows its source document as literally as possible under its own namespace, such as `WHATWG_HTML`. The [repositories](https://github.com/orgs/swift-whatwg/repositories) list them by specification. If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).

> Swift WHATWG is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by WHATWG.
